# Legacy explorer

The active Scarcast app lives at the repository root in `src/`. The independent JavaScript explorer has moved from `frontend/` to `prototypes/legacy-explorer/` so it cannot be mistaken for the active app.

The move preserves the prototype's code, assets, and package files. To inspect it independently, use its own directory and package commands.

The prototype is reference material, not the supported dashboard. Its own README describes example map values as placeholders; it also contains an overlay-manifest validator that may be useful in a future processing pipeline.
